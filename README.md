# Nexora Website

Landing page for **Nexora**, a studio that turns creative ideas into digital experiences. It covers web design, digital ideas and growth, with an about section and a contact call to action.

## Run it

It is a single file, `index.html`, with no build step and no dependencies.

- **Locally:** open `index.html` in a browser.
- **Online:** host it as a static site, for example with GitHub Pages (Settings → Pages → deploy from the `main` branch).

## Project layout

```
index.html   The whole site (HTML and CSS, plus a small script)
```
